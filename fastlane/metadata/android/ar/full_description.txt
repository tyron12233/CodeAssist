CodeAssist بيئة تطوير متكاملة لنظام Android (Android IDE) تعمل على هاتفك وجهازك اللوحي. اكتب بلغتي Kotlin وJava، وشاهد معاينات Jetpack Compose تتحدّث أثناء الكتابة، وابنِ تطبيقات Android حقيقية ووقّعها وثبّتها على الجهاز نفسه. بلا حاسوب، وبلا خادم بناء سحابي، وبلا خدمة Gradle.

إنها بيئة تطوير Android كاملة وليست مجرد ساحة لتجربة الكود: افتح مشاريع Android متعددة الوحدات، وأضف مكتبات من Maven، وأنتج ملف APK أو App Bundle جاهزًا للتثبيت أو النشر.

<b>ابنِ تطبيقات Android على جهازك</b>
• سلسلة الأدوات كلها تعمل على هاتفك: aapt2 ومترجم Kotlin ومترجم Java وتحويل D8 والتحزيم وتوقيع APK
• البناء التزايدي يعيد بناء ما تغيّر فقط
• ثبّت تطبيقك وشغّله بلمسة واحدة، ثم تابع مخرجاته في Logcat
• إصدارات نهائية مع R8 وحزم Android App Bundle (AAB) ومفتاح التوقيع الخاص بك
• مشاريع متعددة الوحدات، ومتغيرات البناء، وViewBinding وAIDL وKSP (Room وHilt) وملف google-services.json لـ Firebase
• تبعيات من Maven Central ومستودع Maven من Google، إضافةً إلى ملفات JAR وAAR المحلية
• استورد مشاريع Gradle موجودة، أو صدّر مشروعك كمشروع Gradle لفتحه على الحاسوب

<b>محرر كود Kotlin وJava</b>
• إكمال تلقائي للكود يعمل حتى مع الكود غير المكتمل، مع استيراد تلقائي
• أخطاء وتحذيرات أثناء الكتابة، مع إصلاحات سريعة بلمسة واحدة
• الانتقال إلى التعريف والتنفيذ والنوع، والبحث عن الرموز، وقراءة مصادر المكتبات
• إعادة تنسيق الكود، وتحسين الاستيرادات، وطيّ الكود، والتفاف الأسطر
• إكمال XML لنظام Android للتخطيطات والبيانات الوصفية والقيم والرسوميات
• شريط رموز للبرمجة، والتكبير بإصبعين، وأنظمة ألوان للمحرر

<b>معاينات Jetpack Compose والتخطيطات</b>
• تُعرض دوال Composable التي تحمل @Preview مباشرةً بجانب الكود وتتحدّث أثناء التعديل
• عاين تخطيطات XML، بما فيها العروض المخصصة، دون تشغيل بناء

<b>مساعد برمجة بالذكاء الاصطناعي</b>
• صِف التغيير بكلماتك. يقرأ الوكيل مشروعك، ويعدّل الكود، ويشغّل البناء، ويعرض فرقًا يمكنك التراجع عنه
• استخدم مفتاحك الخاص من Anthropic Claude أو Google Gemini أو OpenAI أو OpenRouter، أو بوابة متوافقة. مفتاح Gemini المجاني يكفي
• أرفق لقطات شاشة، واذكر الملفات بـ @، وتابع الجلسات المحفوظة لاحقًا

<b>Git وGitHub</b>
• الاستنساخ والإيداع والفروع والدمج وstash والدفع
• سجّل الدخول إلى GitHub لاستنساخ المستودعات الخاصة وفتح طلبات الدمج

<b>تعلّم وتدرّب</b>
• دروس تفاعلية في Java وKotlin مع تمارين تُترجم وتعمل على جهازك
• تحدٍّ برمجي يومي مع لوحة صدارة عامة
• ابدأ من القوالب والتطبيقات النموذجية في متجر المشاريع، أو انشر مشاريعك

<b>مزايا أخرى</b>
• محرر الكتل: حوّل ملف Java إلى كتل بأسلوب Scratch ثم أعده دون فقدان أي حرف
• شغّل برامج Java وKotlin النصية مع وحدة تحكم تفاعلية
• بيئة معزولة تسألك قبل أن يستخدم برنامجك الشبكة أو الملفات أو عمليات أخرى
• إضافات توسّع بيئة التطوير، منها إضافة NDK للغتي C وC++
• سمات فاتحة وداكنة بألوان Material You

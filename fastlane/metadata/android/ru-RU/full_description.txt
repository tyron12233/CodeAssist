CodeAssist — это Android IDE для телефона и планшета. Пишите на Kotlin и Java, смотрите, как превью Jetpack Compose обновляется по мере набора, собирайте, подписывайте и устанавливайте настоящие Android-приложения прямо на устройстве. Без ПК, без облачного сервера сборки, без демона Gradle.

Это полноценная среда разработки для Android, а не песочница для кода: открывайте многомодульные Android-проекты, подключайте библиотеки из Maven и получайте APK или App Bundle, которые можно установить или опубликовать.

<b>Собирайте Android-приложения на устройстве</b>
• Весь тулчейн работает на телефоне: aapt2, компилятор Kotlin, компилятор Java, дексинг D8, упаковка и подпись APK
• Инкрементальная сборка пересобирает только изменённое
• Установка и запуск приложения в одно касание, вывод в Logcat
• Релизные сборки с R8, Android App Bundle (AAB) и вашим ключом подписи
• Многомодульные проекты, варианты сборки, ViewBinding, AIDL, KSP (Room, Hilt) и google-services.json для Firebase
• Зависимости из Maven Central и Maven-репозитория Google, а также локальные JAR и AAR
• Импорт готовых Gradle-проектов или экспорт своего как Gradle-проекта для работы на компьютере

<b>Редактор кода Kotlin и Java</b>
• Автодополнение, которое работает даже в недописанном коде, с автоматическим импортом
• Ошибки и предупреждения по ходу набора, с быстрыми исправлениями в одно касание
• Переход к определению, реализации и типу, поиск символов и читаемые исходники библиотек
• Форматирование кода, оптимизация импортов, сворачивание кода и перенос строк
• Автодополнение Android XML для разметки, манифестов, ресурсов и drawable
• Панель символов для кода, масштаб щипком и цветовые схемы редактора

<b>Превью Jetpack Compose и разметки</b>
• Composable-функции с @Preview отображаются вживую рядом с кодом и обновляются при правке
• Превью XML-разметки, включая ваши собственные View, без запуска сборки

<b>ИИ-помощник для программирования</b>
• Опишите изменение своими словами. Агент читает проект, правит код, запускает сборку и показывает diff, который можно отменить
• Используйте свой ключ Anthropic Claude, Google Gemini, OpenAI или OpenRouter либо совместимый шлюз. Подойдёт и бесплатный ключ Gemini
• Прикрепляйте скриншоты, упоминайте файлы через @ и возвращайтесь к сохранённым сессиям

<b>Git и GitHub</b>
• Clone, commit, ветки, merge, stash и push
• Вход в GitHub, чтобы клонировать приватные репозитории и открывать pull request

<b>Учитесь и практикуйтесь</b>
• Интерактивные уроки Java и Kotlin с упражнениями, которые компилируются и запускаются на устройстве
• Ежедневная задача по программированию с публичным рейтингом
• Начните с шаблонов и примеров приложений из Магазина проектов или опубликуйте свои

<b>А также</b>
• Блочный редактор: переключите Java-файл на блоки в стиле Scratch и обратно, не потеряв ни символа
• Запуск консольных программ на Java и Kotlin с интерактивной консолью
• Песочница, которая спрашивает разрешения, прежде чем программа обратится к сети, файлам или другим процессам
• Плагины, расширяющие IDE, включая NDK-плагин для C и C++
• Светлая и тёмная темы с цветами Material You
